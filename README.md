# 📊 Sales Dashboard - Tableau Project

This repository contains a Tableau Sales Dashboard designed to provide comprehensive insights into sales performance across different regions, products, and time periods. It serves as a portfolio project to showcase data visualization and analytical skills using Tableau.

## 🔍 Project Overview

The Sales Dashboard helps business stakeholders:
- Monitor key sales metrics (Revenue, Profit, Quantity Sold)
- Identify top-performing products and regions
- Analyze sales trends over time
- Drill down into specific segments or categories

## 🛠️ Tools & Technologies

- **Tableau Public** - for data visualization
- **Excel / CSV** - as the data source (can be replaced with SQL or other DBs)
- **GitHub** - for version control and documentation


## 📈 Key Features

- Dynamic filters (Region, Category, Time)
- KPIs at the top (Total Sales, Profit, QTY)
- Monthly trend line chart for sales
- Regional sales performance heat map
- Top 10 products by sales and profit

## 🧠 Learnings & Skills Demonstrated

- Data cleaning and transformation
- Dashboard layout and UX design principles
- Use of calculated fields and parameters
- Storytelling with data through interactive visuals

## 📝 How to Use

1. Download or clone the repository.
2. Open `sales_dashboard.twbx` using Tableau Desktop or Tableau Public.
3. Load `sales_data.csv` if needed or replace it with your dataset.
4. Explore or customize the dashboard.
